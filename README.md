\# GameBall



> Учебный проект на C++ и SFML: шарик, за которым гоняются маленькие треугольники.



\## Идея



Вы управляете шариком, который может летать в любом направлении. За ним охотятся несколько треугольников-врагов с собственной физикой движения, сопротивлением и поворотами. Проект находится в активной разработке, конечная цель ещё не определена — я экспериментирую с физикой, камерой и шейдерами.



\## Управление



\- `W A S D` - движение шарика

\- `F` / `C` - приблизить / отдалить камеру (zoom)

\- `Стрелки` - перемещение камеры

\- `R` - включить/выключить эффект motion blur



\## Сборка (CMake)



Проект собран с помощью CMake. Чтобы скомпилировать его у себя:



```bash

git clone <url-репозитория>

cd <папка-проекта>

mkdir build \&\& cd build

cmake ..

make

```

\##Требования:



\-SFML (>=2.5)

\-Компилятор с поддержкой C++17

\-CMake (>=3.10)



\##Готовый билд

В папке CompleteBuild\_v1 лежит собранная версия проекта — можно сразу запускать без компиляции.
